# Trener

Notatki treningowe Kuby: siła i moc pod BJJ, powrót po ~4 miesiącach przerwy, rozwój klatki i ramion. Plan ma być różnorodny i nie przemęczać obok treningów BJJ.

Eksport pamięci projektu „Trener” z 30.09.2026.
